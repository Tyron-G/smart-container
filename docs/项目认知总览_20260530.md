## 2. 项目一句话理解

`smart-container` 是一个典型的**智能货柜 / 无人零售柜后端微服务系统**，不是单一后台项目，而是由以下几类能力共同组成：

- **管理端能力**：优惠券、运营配置、后台管理
- **用户端能力**：扫码、身份绑定、订单、支付、验证码
- **设备端能力**：设备通信、心跳、开门指令、设备状态处理
- **公共支撑能力**：Feign 接口、公共实体、Redis、RocketMQ、Nacos 等基础设施能力

可以简单理解成：

```text
管理端 + 用户移动端 + 设备通信端 + 微服务协作层
```

## 5. 项目核心模块速览

| 模块 | 主要角色 | 主要职责 |
|---|---|---|
| `container-manager` | 管理端 | 优惠券配置、运营后台能力 |
| `container-order` | 用户端 | 订单、扫码、绑定、验证码 |
| `container-channel` | 用户端 / 第三方 / 内部服务 | 支付、授权、短信、回调 |
| `container-account` | 公共账户层 | 用户身份/账户基础能力 |
| `container-device` | 设备业务层 | 设备状态、开门动作、设备业务处理 |
| `container-communicate` | 设备通信层 | Netty/TCP、协议处理、事件接收 |
| `container-api` | 内部服务契约层 | Feign 接口与 DTO 定义 |
| `container-common` | 公共基础层 | 常量、实体、Redis、RocketMQ、通用能力 |

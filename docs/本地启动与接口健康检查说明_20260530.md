## 3. 本地启动前置依赖

启动服务前，请先确保以下中间件已启动并可访问：

| 组件 | 地址 | 说明 |
|---|---|---|
| MySQL | `localhost:3306` | 本地业务数据库 |
| Redis | `127.0.0.1:6379` | 本地缓存，当前环境开启了密码认证 |
| Nacos | `localhost:8848` | 配置中心 + 注册中心 |
| RocketMQ NameServer | `localhost:9876` | MQ 名称服务 |
| RocketMQ Broker | `localhost:10911` | MQ Broker |

### 3.1 Redis 注意事项

当前本地 Redis 开启了密码认证，项目本地联调中使用的是实际生效密码。若改 Redis 密码：

1. 要同步更新 Nacos 中各服务的 `spring.redis.password`
2. 要确认 `container-common/container-common-redis/src/main/java/cn/fuguang/common/redis/configure/RedissonConfig.java` 能正确读取密码
3. 修改后必须重启 Redis 进程，否则旧密码仍会生效

### 3.2 RocketMQ 注意事项

当前本地 RocketMQ 目录示例：

```text
D:\rocketmq-all-5.5.0-bin-release
```

启动前若脚本被系统拦截，需要先解除阻止；并且启动时要设置：

```powershell
$env:ROCKETMQ_HOME="D:\rocketmq-all-5.5.0-bin-release"
$env:JAVA_HOME="C:\Program Files\Java\jdk-1.8"
```

## 4. 本地配置说明

### 4.1 Nacos 配置中心

当前服务都通过本地 Nacos 拉取配置，因此：

- `bootstrap.yml` 中的 `server-addr` 已切换为 `localhost:8848`
- 各服务依赖 Nacos 中的 `*-dev.yaml` 配置

当前本地联调使用的关键项包括：
- `spring.datasource.*`
- `spring.redis.*`
- `rocketmq.*`
- `mybatis.*`

### 4.2 本地 Nacos 命名空间

本地联调使用了独立命名空间（例如 `container-group` 对应 `smart-container` 项目）。

如需重新配置，请确保：
- Data ID 命名符合服务名，如：
  - `container-order-dev.yaml`
  - `container-account-dev.yaml`
  - `container-channel-dev.yaml`
  - `container-communicate-dev.yaml`
  - `container-device-dev.yaml`
  - `container-manager-dev.yaml`
- Group 为：`CONTAINER_GROUP`

## 5. 启动顺序建议

建议按以下顺序启动：

1. MySQL
2. Redis
3. Nacos
4. RocketMQ NameServer
5. RocketMQ Broker
6. `container-order`
7. `container-account`
8. `container-channel`
9. `container-device`
10. `container-manager`
11. `container-communicate`

### 5.1 为什么要按这个顺序

- 所有服务都依赖 Nacos
- `device` 依赖 Redis、RocketMQ
- `channel` 依赖 Feign 能力
- `communicate` 除 HTTP 外还会拉起 Netty 监听

## 11. 常见问题与排查建议

### 11.1 Maven 明明能编译，服务却起不来
优先检查：
- 是否使用 JDK 8
- 是否拉到了错误版本的 Spring Boot Maven 插件

### 11.2 Redis 报 `NOAUTH` 或 `invalid password`
优先检查：
- Redis 当前实际加载的是哪个配置文件
- Redis 是否重启生效
- Nacos 中 `spring.redis.password` 是否同步更新
- `RedissonConfig` 是否已读取密码

### 11.3 RocketMQ 连不上 `9876`
优先检查：
- `ROCKETMQ_HOME` 是否设置
- NameServer 是否已启动
- Broker 是否已连接 NameServer
- Windows 是否拦截了从 Web 下载的 `.cmd` 脚本

### 11.4 某服务启动时报 Mapper XML 错误
优先检查：
- `jdbcType` 拼写是否正确
- SQL 表名 / 字段名 / 参数名是否与实体一致
- target 目录是否还是旧编译产物

### 11.5 `Unable to find a suitable main class`
优先检查：
- 启动类是否真的有 `main` 方法
- `spring-boot:run` 是否显式指定了 `mainClass`

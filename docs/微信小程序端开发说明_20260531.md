# 微信小程序端开发说明_20260531

## 当前版本

2026-05-31：新增 `miniapp-wechat/` 原生微信小程序预览项目，用于在微信开发者工具中打开和验证用户端页面。

## 已完成页面

| 页面 | 路径 | 说明 |
|---|---|---|
| 首页 | `pages/home/index` | 扫码开柜、订单、账户入口 |
| 扫码开柜 | `pages/scan/index` | 支持 `wx.scanCode` 解析设备和仓门，调用创建订单接口 |
| 我的订单 | `pages/orders/list` | 展示当前客户订单列表 |
| 订单详情 | `pages/orders/detail` | 展示订单基础信息和商品明细 |
| 登录 | `pages/login/index` | 演示用户登录，支持微信开发者工具内 `wx.login` 预览绑定 |
| 我的 | `pages/profile/index` | 展示客户信息和退出登录 |

## 打开方式

微信开发者工具项目目录：

```text
D:\smart-container\miniapp-wechat
```

也可以使用命令行打开：

```powershell
& 'D:\微信web开发者工具\cli.bat' open --project 'D:\smart-container\miniapp-wechat'
```

## 接口边界

当前默认后端地址在 `miniapp-wechat/app.js`：

```js
apiBaseUrl: 'http://localhost:9965/manager'
```

已对接接口：

| 接口 | 方法 | 当前用途 |
|---|---|---|
| `/order/scanResultWithConfirm` | POST | 扫码创建订单 |
| `/api/manager/customer/orders` | GET | 本地演示订单列表 |
| `/api/manager/order/detail` | GET | 本地演示订单详情 |

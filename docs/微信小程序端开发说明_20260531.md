## 接口边界

当前默认后端地址在 `miniapp-wechat/app.js`：

```js
apiBaseUrl: 'http://localhost:9960/order'
```

已对接接口：

| 接口 | 方法 | 当前用途 |
|---|---|---|
| `/order/scanResultWithConfirm` | POST | 扫码生成体验记录 |
| `/order/customer/list` | GET | 用户端记录列表 |
| `/order/customer/detail` | GET | 用户端记录详情和明细信息 |
| `/order/customer/status` | GET | 用户端记录状态查询 |
| `/customer/wechatLogin` | POST | 微信 `wx.login` code 换 openId 并绑定体验用户 |

## 微信登录配置

`container-order` 通过环境变量读取微信登录配置：

```text
MINIAPP_WECHAT_ENABLED=false
MINIAPP_WECHAT_LOCAL_TEST_MODE=true
MINIAPP_WECHAT_APP_ID=wx0650c1e3a558ae28
MINIAPP_WECHAT_APP_SECRET=
MINIAPP_WECHAT_JSCODE2_SESSION_URL=https://api.weixin.qq.com/sns/jscode2session
```

- `MINIAPP_WECHAT_LOCAL_TEST_MODE=true` 且未配置 AppSecret 时，本地联调使用 `wechat-local-{customerId}` 作为演示 openId。
- 真实微信登录需要设置 `MINIAPP_WECHAT_ENABLED=true` 并通过环境变量提供 `MINIAPP_WECHAT_APP_SECRET`，不要写入源码或文档。

# 演示数据维护说明_20260531

## 功能范围

2026-05-31：管理端新增演示数据维护能力，用于在本地或演示环境快速补齐固定用户、订单、设备、优惠券、权限和操作日志数据。

## 接口清单

| 接口 | 方法 | 说明 | 权限 |
|---|---|---|---|
| `/api/manager/demo/summary` | GET | 查询演示数据覆盖度 | `system:audit` |
| `/api/manager/demo/ensure` | POST | 幂等补齐演示数据 | `system:audit` |

## 数据边界

- 不执行清表，不删除支付、退款、审计和页面联调产生的数据。
- 补齐逻辑使用 MyBatis XML 维护，优先 `INSERT ... ON DUPLICATE KEY UPDATE`。
- 对无唯一索引的订单商品明细使用 `WHERE NOT EXISTS` 防止重复插入。
- 前端入口位于运营巡检页“演示数据维护”卡片。

## 覆盖对象

- 用户与签约：`customer`、`black_customer`、`customer_agreement_sign`
- 设备与事件：`device_info`、`gate_info`、`device_event`
- 订单与明细：`order_info`、`order_item`、`order_exception_record`
- 优惠券：`coupon_config`、`coupon_issue_record`、`coupon_use_record`
- 权限与审计：`sys_admin_user`、`sys_role`、`sys_permission`、`sys_user_role`、`sys_role_permission`、`operation_log`

## 接口对接

当前默认后端地址在 `miniapp/app.js`：

```js
apiBaseUrl: 'http://localhost:9965/manager'
```

已对接接口：

| 接口 | 方法 | 当前用途 |
|---|---|---|
| `/customer/bindingAliCustomer` | POST | 支付宝授权绑定 |
| `/order/scanResultWithConfirm` | POST | 扫码创建订单 |
| `/api/manager/customer/orders` | GET | 本地演示订单列表 |
| `/api/manager/order/detail` | GET | 本地演示订单详情 |

## 临时边界

- 订单列表和订单详情本阶段复用管理端只读接口，后续应新增正式小程序用户端接口。
- 支付宝授权绑定需要真实小程序运行环境。
- 微信版当前用于开发者工具页面预览和基础链路验证；微信登录接口已补齐，真实换取 openId 需要后端环境变量配置 AppSecret。
- 支付宝版未提交真实 AppId、密钥、证书或生产配置；微信版已配置真实小程序 AppID，但未提交 AppSecret、商户号、密钥或证书。
- 微信版订单查询不再依赖管理端 token；默认本地后端地址为 `http://localhost:9960/order`。

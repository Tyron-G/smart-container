# smart-container 项目协作说明

本项目是智能货柜业务的 Java Maven 多模块后端项目。

提交规范：

- 不提交本地 IDE 临时文件、构建产物、日志文件和本地环境配置。
- 不将真实账号、密码、密钥、私钥、生产连接串提交到公开仓库。
- 涉及配置变更时，优先使用环境变量、配置中心或本地忽略文件承载敏感配置。
- 修改功能时同步检查并更新相关文档。

技术约定：

- 项目使用 Maven 多模块结构。
- 当前源码目标版本为 Java 8。
- 提交前优先执行 `mvn clean package` 验证构建。

仓库说明：

- GitHub 仓库应保持私有。
- 如需公开发布，应先完成配置脱敏、历史敏感信息扫描和许可证确认。

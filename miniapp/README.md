# smart-container-miniapp

智能货柜用户端小程序源码，当前为 2026-05-31 本地演示骨架版本。

## 功能范围

- 登录页：支持演示用户登录，预留支付宝授权绑定。
- 首页：展示扫码开柜入口、订单入口和账户入口。
- 扫码开柜：支持扫码解析 `deviceId`、`gateId`，并调用后端创建订单。
- 我的订单：本地演示阶段复用管理端只读接口展示订单列表。
- 订单详情：本地演示阶段复用管理端只读接口展示订单基础信息和商品明细。
- 我的：展示当前客户、手机号、绑定状态并支持退出登录。

## 本地打开

使用支付宝小程序开发者工具打开 `miniapp/` 目录。

当前 `app.js` 默认后端地址：

```js
apiBaseUrl: 'http://localhost:9965/manager'
```

如后端端口或网关路径变化，修改 `app.js` 中的 `apiBaseUrl`。
